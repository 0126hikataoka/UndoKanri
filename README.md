# 運動管理アプリ

運動した日をカレンダーに記録して、月・年ごとの回数や「平均何日に1回か」を振り返るWebアプリです。  
iPhone 16 の Safari で「ホーム画面に追加」して、アプリのように使うことを想定しています。

## できること

- **カレンダー**：運動した日に種目ごとの色の点を表示します。日付をタップするとその日の記録が見られます。左右にスワイプすると月を移動できます。
- **ストップウォッチ**：スタート／一時停止／リセット。「記録する」を押すと、測った時間が入った記録画面が開きます。アプリを閉じても計測は続き、計測中は画面が消えにくくなります（対応端末のみ）。
- **記録**：日付・運動の種類・運動時間（ストップウォッチから）・集中度・メモを記録できます。記録はあとから編集・削除できます。
- **集中度**：スライダーで −10（いまいち）〜 +10（良かった）を選べます。初期値は 0 です。
- **運動の種類**：自由に追加・削除できます（名前と色）。種類を削除しても、過去の記録は残ります。
- **分析**
  - 月別：今月と先月の回数、平均◯日に1回（今月・先月・今年）、月ごとの棒グラフ、種目別の回数
  - 年別：年ごとの回数、平均間隔、一番多い種目
  - 画面の一番下：種目ごとに、前回から何日たったか（7日以上あくとオレンジ色で表示）
- **バックアップ**：分析画面の歯車アイコンから、データを書き出し・読み込みできます。

### 数え方

- 「回数」＝運動した**日の数**です（同じ日に複数の種目をしても1回）。
- 「平均◯日に1回」＝ 期間の日数（今日まで）÷ 運動した日数
- 種目別の回数は、種目ごとの記録の数です。

## ファイル構成

```
index.html            画面
style.css             見た目（ダークモード）
app.js                動き・集計
sw.js                 オフラインでも起動できるようにする仕組み
manifest.webmanifest  ホーム画面用の設定
icons/                アイコン
```

ビルドは不要です。ファイルを置くだけで動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作ります（例：`undo-kanri`）。
2. このフォルダの中身（`index.html` などすべて）をリポジトリの一番上にアップロードします。  
   ブラウザなら「Add file → Upload files」にファイルとフォルダをドラッグし、「Commit changes」を押します。
3. リポジトリの **Settings → Pages** を開きます。
4. 「Build and deployment」の Source を **Deploy from a branch** にして、Branch を **main / (root)** にして Save します。
5. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

## iPhone に入れる手順

1. iPhone の **Safari** で上のURLを開きます。
2. 下の共有ボタン（□に↑）→「**ホーム画面に追加**」をタップします。
3. ホーム画面のアイコンから起動します。以降はこのアイコンから使ってください。

## 注意

- 記録は **iPhoneの中（そのアプリの保存領域）だけ** に保存され、サーバーには送られません。
- Safari で開いたページと、ホーム画面に追加したアプリでは、保存場所が別になります。ホーム画面のアプリから使ってください。
- アプリを削除すると記録も消えます。機種変更の前などは、設定からバックアップを書き出してください。
- リポジトリを公開（Public）にしても、公開されるのはアプリのプログラムだけです。記録は公開されません。

## 更新するとき

`app.js` などを書き換えたら、`sw.js` の先頭にある `CACHE = 'undo-kanri-v2'` の番号を上げて（`v3` など）アップロードしてください。  
アプリを開き直すと新しい版に切り替わります（反映に2回ほど開き直しが必要なことがあります）。
